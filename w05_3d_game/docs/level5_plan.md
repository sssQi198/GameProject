# 第5关「血肉教室」重建规划书 v2.0

## 1. 设计目标

将第5关从"门缝里的小贴图"升级为**覆盖整个教室的沉浸式血肉内脏场景**，在纯 Three.js 程序化生成（无 GLB 模型）的前提下，用多层几何体+动态纹理+动画实现"教室被活体器官覆盖"的视觉冲击。

---

## 2. 整体布局

```
                      ┌──────────────────────────────┐
                      │      前墙 (+Z) 血肉覆盖         │
                      │  ┌──────────┐                 │
  左墙 (-X) 血肉       │  │  门(半开) │                 │ 右墙 (+X) 血肉
                      │  └──────────┘                 │
                      │      后墙 (-Z) 血肉覆盖         │
                      └──────────────────────────────┘
                          天花板：裂缝+器官悬垂
                          地板：血管网络+血肉
                          空间中央：巨型器官柱
```

- **范围**：教室 `20m × 12m × 3.2m`，六面全包裹
- **拍照目标**：天花板裂缝中的一对巨大红色眼睛 + 器官上的次要眼睛
- **玩家站位**：`(0, z=4.2)` 面向门方向

## 4. CanvasTexture 设计（512×512）

| 层 | 内容 | 透明度 | 颜色 |
|---|---|---|---|
| 底色 | 径向渐变 | 100% | `#3a0a14` → `#6a1e2a` → `#3a0a14` |
| 纤维层 | 正弦波纹，竖/横交错 | 12% | 亮红灰 `rgba(100,30,20,α)` |
| 血管层 | 随机曲线，分支 | 25% | 深紫红 `rgba(80,15,30,α)` |
| 脂肪层 | 径向渐变斑点 | 10% | 淡黄 `rgba(180,160,130,α)` |
| 阴影层 | 凹凸感矩形渐变 | 15% | 黑色，模拟肌肉纹理 |
| 裂痕 | 随机裂纹 | 80% | 黑色 `#010102` |

纹理尺寸 512×512，在墙面 `repeat.set(4, 3)` 平铺。

## 5. 核心 3D 组件规格

### 5.1 巨型心脏（教室中央，位于 0, 1.6, 0）

```js
const heartGeo = new THREE.SphereGeometry(0.8, 20, 16);
heartGeo.scale(1.1, 0.9, 0.7); // 压扁更像心脏
```

- 材质：`MeshStandardMaterial`，`color: 0x6a1a2a`，`roughness: 0.7`，`metalness: 0.1`
- 血管凸起：6个小的半椭球体，随机分布在表面
- **动画**：每帧缩放 `1 + 0.005 * sin(time * 1.2)` — 模拟心跳

### 5.2 气管/食管（从天花板垂下）

- 用 `TubeGeometry` 沿一条 3-D 三次贝塞尔曲线生成
- 曲线控制点：起点 `(0, 3.15, 2.5)` 到终点 `(0.3, 2.0, 2.0)`
- 管半径 0.06~0.10 渐变
- 颜色 `#4a1020`，半透明 `0.6`

### 5.3 肌肉束（横向排列，教室两侧）

- `CylinderGeometry(0.08, 0.08, 0.6, 8)` 压扁到 Y 轴 0.3
- 沿 `z ∈ [ -5, 5 ]`, `y ∈ [ 0.5, 2.8 ]` 分布
- 材质：`MeshStandardMaterial` 暗红 `0x5a1420`，半透明 `0.5`
- **动画**：每帧沿 X 轴正弦位移 `±0.003 * sin(time * 1.5 + phase)`

### 5.4 血管管网

- **主动脉**：TubeGeometry，从心脏向上到天花板分叉，半径 0.04
  - `color: 0x4a0a1a`，半透明 0.7
- **毛细血管**：`LineSegments` 用 `BufferGeometry` 随机点
  - 300 条线段，随机分布在墙面
  - `color: 0x2a0510`

### 5.5 肋骨碎片（从裂缝/墙面伸出）

- 用 `BoxGeometry(0.02, 0.15, 0.04)` 压扁，一端压尖（`BufferGeometry` 手动改顶点）
- 6~10 片，从墙面和天花板裂缝边缘伸出
- 颜色 `#c8c0b0`（骨色），沿边缘半透明泛红

### 5.6 脂肪结缔组织

- `SphereGeometry` 压扁到 Y 轴 0.3
- 半径 0.08~0.14，随机分布在墙面
- 材质：半透明 `0.7`，颜色 `#c8b890`
- 共 8~12 个

### 5.7 肺叶（地板两侧）

- `SphereGeometry(0.5, 12, 10)` 压扁
- 位置 `(±1.2, 0.3, -2.5)`
- 半透明 `0.4`，颜色 `#7a2840`

### 5.8 肠道（地板）

- `TubeGeometry` 沿随机弯曲路径
- 半径 0.04
- 颜色 `#5a1420`

## 6. 裂缝与眼睛（拍照目标）

### 6.1 主裂缝

- 形状：不规则多边形，用 `Shape` + `ShapeGeometry`
- 尺寸：宽 2.8，深 1.0
- 位置：天花板 `(0, 3.18, 1.5)`
- 边缘泛红：沿着裂缝长度添加 2~3 条红色 `LineSegments`

### 6.2 主眼睛 × 2

- `SphereGeometry(0.14, 14, 10)`
- 位置：`(±0.38, 3.18, 1.55)`
- 材质：`#ff1020`，`toneMapped: false`
- 瞳孔：`SphereGeometry(0.055)`，黑色
- 发光晕：大 2.5 倍球体，半透明红色，`opacity: 0.3`
- **动画**：
  - 心跳缩放：`scale.x = 1.2 * (0.8 + 0.2 * sin(time * 1.2))`
  - 瞳孔闪缩：`pupil.scale = 0.3 + 0.1 * sin(time * 2.5)`
  - 发光呼吸：`opacity = 0.25 + 0.08 * sin(time * 2.3)`

### 6.3 次要小眼 × 3~5

- 尺寸：半径 0.02~0.04
- 随机分布在肉墙表面
- `flickerDark` 时为 `opacity: 0.8`，否则 `opacity: 0.1`

## 7. 粒子系统

### 7.1 血雾

```js
const mistGeo = new THREE.BufferGeometry();
const mistPos = new Float32Array(300 * 3);
// 随机位置在教室空间内
const mistMat = new THREE.PointsMaterial({
  color: 0x441020, size: 0.03, transparent: true, opacity: 0.15,
  depthWrite: false, blending: THREE.AdditiveBlending,
});
```

- 每帧 Y 轴缓慢漂移 `+0.003 * sin(time + phase)`

### 7.2 飞溅液滴

- 50 个粒子，在肌肉束附近随机跳动
- 每帧 `p.y += sin(time * 5 + p.phase) * 0.005`

## 8. 动态效果汇总

| 事件 | 效果 |
|---|---|
| 每帧 | 心脏跳动（整体缩放 1 + 0.005*sin(t*1.2)） |
| 每帧 | 肌肉束蠕动（±0.003 正弦位移） |
| 每帧 | 血雾漂移 |
| 每帧 | 眼睛心跳 + 瞳孔闪缩 + 发光呼吸 |
| 灯灭 flickerDark | 次要小眼睁开（opacity 0.8） |
| 灯灭 | 血管变亮（color 偏移） |
| 灯灭 | 裂缝边缘红色发光增强 |
| 被拍照后 | 所有眼睛剧烈缩放一次（1.5×），然后恢复（2秒） |
| 被拍照后 | 心脏剧烈收缩一次，血雾变浓 0.5s |

## 9. 性能控制

- 总网格数目标：< 80（六面墙 6 + 器官 30 + 眼睛 15 + 碎片 15 + 其他）
- 粒子 350 个，不参与阴影
- 所有材质 `MeshBasicMaterial`，不计算光照（除心脏可用标准材质）
- `frustumCulled = true`（Three.js 默认）
- 纹理 512×512 可复用，CanvasTexture 只需生成一次
