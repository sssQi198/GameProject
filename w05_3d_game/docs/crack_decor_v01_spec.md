## 坐标与朝向

* 局部原点 = **L 形转角 = 世界 (0, 3.09, -5.92)**。这是前墙裂缝所在的平面，
  也是天花板裂缝臂的 y。
* Blender 里：墙臂沿 **-Z** 向下，天花板臂沿 **-Y** 伸进房间，正面朝 **-Y**。
  导出 glTF（Y-up）后正面朝 **+Z**，游戏里整件放在 `(0, 3.09, -5.92)`，
  不旋转、不缩放。
* 世界包围盒（`_probe/crack_decor.mjs` 实测）：
  * min = `(-1.1898, -0.0266, -5.9828)`
  * max = `( 1.3129,  3.1528, -3.3148)`
  * 最靠墙 -5.9828，没有穿到墙面 -5.99 后面；顶部 3.1528，没有穿到天花板 3.16；
  * 底部 -0.0266 是地面根须/血滴的底，2.7 cm 埋在地板下，游戏里看不见。
* 翻边内边界**直接复刻** `anomalies.js` 的开口轮廓：同一个 LCG 种子 `20251102`、
  同一个 `AP = 0.34`。所以模型和程序化深渊、黑色巨脸、眼睛、牙对得上。

## 网格

* **4 条翻边壳**：前墙左/右各一条、天花板左/右各一条。每条是沿开口边放样的闭合管，
  两端各一个 n 边形盖。
  * 横截面 18 个点：内唇 → 唇脊 → 唇下凹槽 → 内圈 → 台坎 → 中圈 → 台坎 → 外圈 →
    外缘裙边 → 底面 → 回洞缘。唇脊鼓出 6.2 cm，唇下有一道凹下去的暗袋。
  * 前墙路径 20 个采样，天花板 18 个；宽度沿路径 0.21–0.46 m，
    叠低频鼓包 + 高频锯齿 + 3 处肉瓣 + 2 处深 V 撕口。
* **表面起伏（fbm）**：上表面顶点沿房间法线 ±8 mm、沿宽度 ±5 mm 抖动，
  起伏随离洞缘越远越强，内唇钉死在 AP 开口上。这让肉面不再是一条光滑放样带。
* **21 根触手**：5–7 边 × 5 段，长度 0.275–0.595 m，根半径 1.8–4.0 cm；
  带环纹（半径/明暗随长度正弦起伏）、扭转、尖端钝圆并微微鼓起；
  每段随机弯，x 分量强制朝外，点被夹在房间内。
* **54 颗肉芽**：内唇成簇（大小两两一组），外半圈散芽 + 大肉瘤；
  低面数 icosphere 沿翻边法线压扁到 0.62，底部暗、顶面亮。
* **13 条肉片**：从外缘撕出来的 0.10–0.28 m 扁平薄片，尖端微翘。
* **12 滴血滴**：挂在墙臂唇边往下滴，上面细、底部鼓成一团，落到地板就停住。
* **10 根组织细丝**：3 边细管，直径 2–4 mm、长 0.07–0.22 m，受重力下垂。
* 所有零件 join 成 1 个 mesh：**3658 顶点 / 4186 面 / 6860 三角**（导出 5072 顶点）；
  0 非流形边、0 边界边、0 孤立点；113 个连通岛。
* 洞心没有任何面。`_probe` 直接读 glb 顶点验证 `|x|<8 cm、0.7<y<2.6` 内为 0。

## 真实感处理

* **湿高光 + 环境闭塞**：唇脊是整件最亮的一线（模拟被血浸湿、反光的卷唇），
  唇下凹槽、触手根、肉芽根、底面被压暗（模拟自遮挡）。明暗全部烘进顶点色，
  游戏里没有灯光也读得出体积。
* **内切面肌纤维**：洞缘厚度那一圈（s≈0）叠了纵向明暗条纹，像被撕开的肌纤维。
* **血渍/斑驳**：墙臂外半圈叠了垂直血渍条纹；整条翻边再乘一层低频斑驳，
  避免颜色是一整块平涂。
* **颜色仍只留暗红到近黑**：近黑 28.8%、深红 28.7%、暗血红 22.7%，
  其余落在两者之间；G/B 最大 0.00749。色相不加法，体积靠明暗和结构。
* **灰度血肉细节贴图**：另画了一张 512² 可平铺的灰度贴图（`crack_detail.png`），
  含斑驳、瘀血斑块、纵向肌纤维、血点，均值 ~0.9；叠在顶点色上做乘法细节，
  只压暗、不洗白，把「一整块平涂」变成「有颗粒/纤维/血渍」的表面。

## 材质与顶点色

* 材质 `CrackDecor_Flesh`：Base Color = 顶点色 `Col` × 细节贴图，
  Metallic 0、Roughness 1.0、单面、无自发光、无扩展。
  glTF 里 `baseColorFactor` 缺省（白），颜色由 `COLOR_0 × baseColorTexture` 决定。
* `Col` 是 FLOAT_COLOR / POINT，写**绝对线性颜色**，导出成 `COLOR_0`（VEC3 float）。
  实测 R ∈ [0.00004, 0.2507]，G/B ≤ 0.00749。
* 底色（sRGB）：洞缘 `#050001`、唇 `#7a0d12`、唇脊湿高光 `#7a0d12`（×1.16）、
  唇下暗袋 `#120103`、内圈 `#1a0203`/`#2a0406`、中圈 `#4a060b`/`#56080d`、
  外圈 `#6a0b10`/`#56080d`、外缘 `#2a0305`、底面 `#080102`；
  触手根 `#1e0204`→尖 `#8a0e14`；血滴 `#1e0204`→`#8a0e14`；细丝 `#4a060b`→`#7a0d12`。
* 细节贴图是 sRGB 灰度、REPEAT 平铺，内嵌进 glb；UV：翻边 U=弧长×3 / V=横截面 s×2，
  触手/血滴/细丝 U=长度 / V=周向，肉芽用位置映射。贴图只做明暗细节，不做色相。
* 游戏里统一换成
  `MeshBasicMaterial({ color: 0xffffff, map: 细节贴图, vertexColors: true, side: DoubleSide,
  fog: false, toneMapped: false })`：
  不吃光、不进雾、不被 ACES 二次压色；`贴图 × 顶点色` 就是最终颜色。

## 还没做的事 / 已知取舍

* 细节贴图是**灰度乘法细节**（不做色相），所以三层翻边的红/黑仍由顶点色决定；
  它只负责把平涂变成有颗粒/纤维/血渍。想要真正的污渍/皮下组织色相，
  得换一张带色相的 albedo 并把顶点色改成灰度乘数，代价是三层翻边色要靠贴图重新画。
* 「单网格」是 1 个 mesh / 1 个 primitive，但里面是 113 个互不相连的岛
  （4 条翻边壳 + 21 根触手 + 54 颗肉芽 + 13 条肉片 + 12 滴血滴 + 10 根细丝）。
  要焊成一整块水密体，得重做所有接缝，会明显增加面数和接缝闪烁。
* 整件和旧的程序化裂缝一样，浮在墙面前方 7 cm、天花板下方 7 cm；
  外缘裙边离墙还有约 1.5 cm，贴墙斜看会看到一条细缝。这是为了不穿进墙里、
  也不和血肉墙面闪面。
* 洞心不封闭：深渊、背板、巨脸、眼睛、牙都由游戏程序化/其他 glb 填。
  单独打开 glb 看到的是一个空框，这是提示词要的「nothing inside the hole」。
* 装饰没有单独碰撞，也没有 `noRay`；它参与拍照射线。当前几何验证过不挡眼睛，
  以后若把触手再加长，必须重跑 `node _probe/crack_decor.mjs` 第 7 段。
* 地面根须和血滴有约 2.7 cm 埋在地板下（血滴落在底唇时被夹到地板线上），
  天花板/墙面外没有多余几何；这些都在可见范围里被地板/天花板挡住。
