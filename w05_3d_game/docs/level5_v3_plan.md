# 第5关·血肉墙 v3.0 改造规划书

> **状态：已全部完工。** v4.0 重大重构：放弃 ShapeGeometry，改用纯 PlaneGeometry 分上下半。后墙 (zMax) 血肉自动避开门区域。移除所有洞/眼/触手/裂缝代码。血管贴附天花板+墙壁表面（不再悬空）。语法检查全部通过。

| 项目 | 改动 | 优先级 |
|------|------|--------|
| A. 天花板改为血肉全覆盖 | 去掉 `PlaneGeometry` 天花板，用新的覆盖网格替代 | P0 |

## 二、详细方案

### A. 天花板血肉全覆盖

**现状**（第1248–1258行）：一片 `PlaneGeometry` 用 `fleshMat` 纹理，`repeat.set(4,3)`。

**改造**：
- 用 `ShapeGeometry` 拟合教室天花板轮廓（`xMin~xMax, zMin~zMax`），贴 `fleshMat` 不变
- 纹理 `repeat` 从 `(4,3)` 加大到 `(6,4.5)`，让肌肉纤维纹理更细密
- 在 CanvasTexture 的流动动画（`flowTime`）基础上，添加**天花板肉膜起伏**：用 Vertex shader 或 position 修改实现轻柔呼吸效果（第 F 部分详述）

### B. 墙壁半覆盖：从上往下蔓延约一半高度

**现状**（第1267–1286行）：四面墙壁都是完整的一整面 `PlaneGeometry`，覆盖全部高度 `yCeil = 3.2`。

**改造为两段式墙壁**：

每面墙拆成两段：

1. **上半段（血肉覆盖层）**：`yCeil/2 ~ yCeil`（约 1.6m~3.2m），贴 `fleshMat` 材质
2. **下半段（保持原教室风格）**：`0 ~ yCeil/2`，贴原教室墙壁材质（深色灰墙或保留干净面）

**下边缘处理**：不是平直一刀切，而是用噪声生成**不规则锯齿/撕裂边缘**，模拟血肉从天花板"滴淌蔓延"至墙壁一半高度的自然感。

具体实现：
- 对每面墙，用 `PlaneGeometry` 裁剪或 Shape 剪切出上半部分
- 下边界用 fbm 噪声 + 随机函数生成波浪曲线，确保每面墙边缘不同
- 或者用 `Shape` 描出上半部轮廓生成自定义几何体

### C. 立体血管（TubeGeometry）

**全新模块**，位于墙壁/天花板血肉层表面。

**生成规则**：
1. 随机在血肉覆盖区域的表面（上半墙和天花板）选起点
2. 用 CatmullRomCurve3 生成路径，沿墙平面随机蜿蜒 10~20 个控制点
3. TubeGeometry 半径 0.015~0.05（分主血管/分支），颜色 `0x3a0a0a` 到 `0x5a1018`
4. **微微跳动**：在 `update(dt)` 中给每个管道的缩放加上正弦波，频率 0.8~1.2Hz，幅度 3%~8%
5. 每条血管从起点到终点渐变细（类似触手尖端的压细逻辑）
6. 数量：约 15~25 条主血管 + 每条的 2~3 条分支，覆盖天花板和上半墙

**分支结构**：
```
主血管（粗，r=0.03~0.05）─┬─ 分支（中，r=0.02~0.03）
                          ├─ 分支（中）
                          └─ 细支（r=0.015~0.02）
```

**跳动实现**：
```javascript
// update(dt) 中
for (const v of veins) {
  const pulse = 1 + Math.sin(v.phase + flowTime * v.freq) * v.amp;
  v.group.scale.set(pulse, 1, pulse);
}
```

### D. 裂缝核心（洞+触手+巨眼）优化

**现状**（第1288–1500行）：现有洞、触手、巨眼代码保留，但需调优：

1. **洞的形状**：半椭圆 `holeW=3.0, holeH=1.8`，扩大至 `holeW=3.5, holeH=2.2`
2. **洞内深度感**：加强黑色遮挡 `opacity` 从 0.95→1.0，红光球从 `opacity=0.15`→`opacity=0.25`
3. **巨眼**：`eyeR0=0.28` 加大至 `0.35`，眼位微调更居中；瞳孔添加缓慢扫视动画（已经实现了 `lookX/lookY`）
4. **血管包围眼**：现有血管丝加粗（从 `0.006`→`0.008`），数量从 12 条增至 18 条
5. **触手**：现有触手的颜色加深，`opacity` 从 0.85 变为 0.95

### E. 移除元素

| 移除项 | 原因 | 所在行 |
|--------|------|--------|
| 肌肉束（横向排列的 Cylinder） | 与"天花板蔓延"风格不统一，过于抽象 | §5, ~1504行 |
| 肋骨碎片 | 原为旧裂缝设计，现在是大洞风格，不适配 | §8, ~1555行 |
| 脂肪结缔组织 | 纹理里已有脂肪斑点，立体脂肪块冗余 | §9, ~1594行 |
| 瘀伤斑点 | 与天花板蔓延主题无关 | 纹理内 1f 保留即可 |

### F. 天花板肉膜呼吸动画

用更新循环实现天花板的细微起伏：

- 在天花板网格的 `geometry.attributes.position` 上应用 Y 轴偏移
- 偏移量 = `sin(flowTime * 0.8 + x * 2 + z * 1.5) * 0.015`
- 频率与玩家的心跳节奏联动（`env.heartRate` 或单独）

### G. 纹理增强（CanvasTexture）

在现有纹理层（基底→肌肉纤维→血管→毛细血管→脂肪→瘀伤→高光）基础上追加：

- **8. 肉膜液面反光层**：在纹理顶部 20% 的区域增加随机高光斑，模拟潮湿感
- **9. 纹理顶部（对应天花板）加深**：从纹理 Y=0~0.2（顶部）到 0.2~0.5 渐变深红色，对应墙壁上半部的"往下蔓延"效果
- **流动偏移**：当前 `texture.offset.y` 已用于血流动画，增加 `texture.offset.x` 的微幅漂移（`sin(flowTime * 0.1) * 0.005`）
