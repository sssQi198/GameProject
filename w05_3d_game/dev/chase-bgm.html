距离 → 音量：左端 = 怪物很远 = 0 dB（素材自己的电平，比默认 BGM 高 1.9 dB）， 右端 = 贴着背 = +4 dB（峰值 0.622 × 1.585 ≈ 0.986，不削波）。 中间是按 dB 线性插值的，不是按增益线性——所以「近了一点」听起来才是均匀地变响。 游戏里这条曲线由 game.js 每帧按怪物距离算出的 tension 驱动， audio.setTension() 只是把它转给 chasefile.js。
接缝：MP3 开头有 31 ms 编码器延迟静音，末尾是硬切。原样 loop = true 每圈会「咔」一下， 所以解码后在内存里掐掉 31 ms、把最后 45 ms 等功率淡化到开头，45.024 s 变成 44.948 s。 磁盘上的 mp3 一个字节没改。「跳到最后 3 秒」就是专门听这个接缝的。
