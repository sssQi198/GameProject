# 错层 Wrong Floor

可玩的项目在 [`w05_3d_game`](w05_3d_game/)。

Windows 上双击 `w05_3d_game/start.bat`，或在该目录运行 `node server.js`，然后打开 http://127.0.0.1:5173 。

操作、演示模式和已知限制见 [w05_3d_game/README.md](w05_3d_game/README.md)。设计文档和课程要求在 [w05_3d_game/docs](w05_3d_game/docs/)。

探针、旧发布包、备份和做图时的中间文件在 [`_多余`](_多余/)。游戏运行不读这些文件。
